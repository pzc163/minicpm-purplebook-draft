# 公开混凝土裂纹测试子集

来源：Çağlar Fırat Özgenel，Concrete Crack Images for Classification，version 2，2019-07-23。

- 原始页面：https://data.mendeley.com/datasets/5y9wdsg2zt/2
- DOI：10.17632/5y9wdsg2zt.2
- 许可：CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。保留作者、版本和来源；本子集仅抽样，图片像素未修改。
- seed=20261015，每类随机10张，20张内容哈希不同的227×227 JPEG。
- 原数据由458张高分辨率照片裁剪；数据包不含可靠的原场景分组映射，不能把20张裁剪图称为20个独立现场，也不能估计现场泛化准确率。
- 样本01–10为来源正类，11–20为来源负类。对照contact-sheet人工检查；20号细线/表面纹理有视觉边界歧义。
- 手机测试使用原始227×227 JPEG，模型单次加载、每图清理上下文；这组耗时不代表3072×4096相机采集和1280压缩流程。
- 只有裂纹/正常表面两个范围；暗光、模糊和遮挡的自然实拍尚未包含。
- 私有照片不在此目录或上传包中。
