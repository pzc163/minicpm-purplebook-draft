# 第五章真实照片采集

本目录目前仅有标注模板，没有真实视觉测试结果。

1. 选择可拍摄且有使用权限的灯具、墙面、地面或门框。没有缺陷时按真实正常场景标注，不制造缺陷。
2. 为同一对象拍清晰近照、暗光、轻微失焦/移动模糊、部分遮挡照片。遮挡不要用手遮住整个镜头。
3. 再拍正常场景；缺位置组可使用一张真实图片但位置输入留空。这是应用输入测试，不能重复计为独立视觉样本。
4. 图片保存到 images/，在 annotations.template.jsonl 副本中填写对象、照片可见现象、来源和许可。模板中的待填值不能作为标注。
5. 同一对象连拍用相同 scene_id；按对象分组划分调试/最终测试。最终至少 20 张连续性能测试照片可与准确率测试共用，但分别统计。
6. 真实业务照片无需公开；只有明确许可公开的素材才用于魔搭数据集发布。

每张图片人工核对模型原始输出、对象、可见现象、无依据推断及修改前后字段。不能用示例 JSON 代替图像推理。
